# PraK Retrieval Layer

This markdown describes which retrieval operations are valid.


## Text Query

LLM needs to specify the text

## Temporal Query

LLM needs to specify both texts

## Bayes Update

LLM needs to specify positive examples

## LoadVideoSumary

LLM needs to specify single positive example

## Intra Video Query

LLM needs to specify single positive example + query

## Image Query

LLM needs to specify single positive example

## Load More

needs no input.
